Task 4（Claude Code）完整操作指南

适用于 Mac · 终端版（4B）· 按顺序做，每完成一项打勾

一、开始前自查清单（软件 / 账号 / 环境）

项目怎么检查 / 怎么装
☐网络能打开 claude.ai 浏览器打开 claude.ai 能加载即可。
如果显示 ERR_NAME_NOT_RESOLVED，或终端 nslookup claude.ai 显示 REFUSED，说明当前网络在拦截 Claude，请改用手机热点（iPhone 打开「最大兼容性」）。整个任务都用同一个网络。
☐Claude 账号（Pro 或以上） 能在 claude.ai 登录即可。Claude Code 与网页版共用额度（5 小时滚动重置）。
☐Chrome 浏览器 用于登录、打开问卷、查看做好的应用。
☐Claude Code（命令行版） 终端里运行：
curl -fsSL https://claude.ai/install.sh | bash
装完如提示 PATH，再运行：
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc
检查：claude --version 显示版本号即成功。然后退出终端（command+Q）。
☐Node.js（LTS 版） 到 https://nodejs.org 下载 macOS Installer (.pkg)，一路「继续 → 安装」。
检查：终端运行 node -v 显示版本号。
（React + Vite 项目必须有它才能运行。建议提前装好，不占任务时间。）
☐Xcode 命令行工具（可选） 系统若弹出「安装软件」窗口，网络快就让它装完；显示要几十小时就点取消。
☐任务包已解压 文件夹 Task 4 - Claude Code - Collaborative，里面有：Check Submission.command、Start Claude Code (Desktop/Terminal).command、Start Recorder.command、Task 4 Instructions - Claude Code.docx、Task 4 Starter、Tools。
☐清理旧录屏 「下载」里如已有 records 文件夹，先移到别处。
☐录屏工具 4 项授权 见第二部分第 2 步，4 项都显示绿色 GRANTED。
macOS 安全拦截的两种处理方法（.command 文件和 Tools 里的程序第一次打开都可能遇到）
1）提示「无法验证…是否包含恶意软件」：点 完成/Done（不要点「移到废纸篓」）→ 系统设置 → 隐私与安全性 → 往下滚 → 仍要打开 / Open Anyway → 输入密码。
2）提示「已损坏，无法打开（damaged）」：点 取消 → 打开一个新的终端窗口（不是 Claude Code 窗口），输入下面这段（末尾有空格），把程序图标拖进终端窗口，再按回车： 
xattr -dr com.apple.quarantine

二、完整流程（共 10 步）

第 1 步　解压任务包

双击收到的 ZIP，得到任务包文件夹。

第 2 步　设置录屏工具（Computer Recorder）

  1. 双击 Start Recorder.command（被拦截就按上面的方法处理）。
  2. 每一项点 Set Up → 在系统设置里给 Computer Recorder 打开开关 → 回来点 Check Again：
    项目系统设置位置
    Downloads Folder弹窗点「允许」
    Screen Recording隐私与安全性 → 屏幕与系统音频录制
    Accessibility隐私与安全性 → 辅助功能
    Input Monitoring隐私与安全性 → 输入监控
  3. 提示「退出并重新打开」就照做。User Name 保持 anonymous，Debug / Show Logs 不勾。
  4. 4 项都是 GRANTED 后，先不要点 Start。

第 3 步　准备工具

确认第一部分自查清单都打勾了（Claude Code 已安装、Node 已安装、旧 records 已移走）。

第 4 步　启动 Claude Code（4B 终端版）

  1. 双击 Start Claude Code (Terminal).command（不要自己在终端里输入 claude 启动）。
  2. 选主题：直接回车。登录方式：选 Claude account → 浏览器登录 → 看到「You're all set up for Claude Code」后回到终端。
  3. 「Do you trust the files in this folder?」→ 选 Yes, I trust this folder。
  4. 确认顶部显示 Sonnet 5.5 with medium effort，路径结尾是 Task 4 Starter。不要改模型。

演示视频：
4B 终端版（57 秒）：https://drive.google.com/file/d/1aoJQaoxPLyMq5jHTH8iyRZBuqacsKhby/view
4A 桌面版（55 秒，如选桌面版）：https://drive.google.com/file/d/1bmeYzIV8Xsit40WvX9V4cRX1ddOTbnjr/view

4A 和 4B 只能二选一，全程只用一个；不要加个人设置、插件或连接器。

第 5 步　开始录屏

Computer Recorder 里点绿色 Start，右上角显示 Running。

第 6 步　读任务并开始（从这里计时 1 小时）

  1. 打开 Task 4 Starter/Task 4.pdf 浏览一遍。
  2. 在 Claude Code 的 > 输入框粘贴（command+V）并回车： 
    请阅读这个文件夹里的 Task 4.pdf，按照要求做一个项目规划网页应用。用 React + Vite，数据存在 localStorage，满足 Acceptance checklist 的所有项目，并写一个 README 说明怎么安装和运行。
  3. 它提问时：方向键选择、回车确认，答完到 Submit 回车。问你「可以运行吗」选 Yes。
  4. 做完后输入：
    帮我运行一下试试，告诉我在浏览器里打开哪个网址
  5. 在浏览器打开（通常是 http://localhost:5173）按验收清单测试：
    • ☐ 改项目标题和描述　☐ 添加多个任务　☐ 添加子任务（缩进显示）
    • ☐ 改状态 / 优先级，进度条变化　☐ 编辑任务　☐ 删除任务
    • ☐ command+R 刷新后数据还在　☐ 新建第二个项目并切换　☐ 文件夹里有 README
  6. 有问题用中文直接告诉 Claude，例如「刷新后数据没了，请修好」。

小提示：输入框里的灰色文字只是建议，按 Tab 采用，或直接自己输入。esc = 取消/打断。用 /usage 查看额度。
演示视频（第 5–6 步，32 秒）：https://drive.google.com/file/d/1DNiRY-5JRx_kAmL3u1zFUNh5T0LcYN8R/view

时间以你的 Mac 右上角时钟为准。到 1 小时还没做完也没关系：停下来，提交已有的部分。

第 7 步　停止录屏

  1. Computer Recorder 点 Stop，显示 STOPPED。
  2. 访达 → 下载 → records → screenshots，确认最新截图是几分钟前的。没有的话回复邀请邮件。
  3. 在 Claude Code 里输入 /exit 退出。之后不要再往 Claude Code 窗口里粘贴任何东西，需要用终端就按 command+N 开新窗口。

第 8 步　填问卷（不用 AI）

问卷链接：https://project-planner-post-task.glisteningchaff.chatgpt.site

  • 用报名时的邮箱登录 Google。
  • 独立作答，不用 AI（包括用 AI 解释题目）。看不懂就照实写「不清楚」，把握度照实选。
  • 答完点 Next，停在 Final submission 页面，不要关。

第 9 步　导出会话日志（Agent Trajectory Logger）

  1. 打开 Tools/Agent Trajectory Logger（被拦截就按第一部分的方法处理）。
  2. 点 Choose project folder → 进入 Task 4 Starter → 直接点 Choose。
  3. 在 Coding sessions 里选首条指令是「请阅读这个文件夹里的 Task 4.pdf…」的那一行。
  4. 点 Save log ZIP，保存到桌面。

演示视频（第 7、9 步，1 分 13 秒）：https://drive.google.com/file/d/1ghZlZ2HkynOx26-qRUYVE9VsrSGqSNe4/view

第 10 步　打包、检查、上传

  1. 桌面按 command+shift+N 新建文件夹（如 Task4_submission）。
  2. 按住 option 拖动（复制）三样东西进去：
    • 下载里的整个 records 文件夹
    • 第 9 步导出的日志 ZIP
    • 整个 Task 4 Starter 文件夹（代码 + README）
  3. 右键该文件夹 → 压缩，得到 ZIP（上限 1 GB）。
  4. 双击任务包里的 Check Submission.command，选这个 ZIP：
    结果怎么办
    OK没问题
    FIX按提示改好，再检查一次
    REVIEW核对标出的时间；那段时间你在看东西或等待 → 直接上传，不用发邮件
    缺少录屏回复邀请邮件
  5. 回到问卷 Final submission 页面 → Add file 选 ZIP → 等上传完 → 点 Submit。
  6. 看到「Your response has been recorded」即全部完成。
完成！代码可以放进你的作品集。

三、常见问题速查

现象原因 / 解决
claude: not found没装 Claude Code 或 PATH 没设置，见第一部分。
claude.ai 打不开 / REFUSED当前网络拦截，换手机热点。
Mac 连不上 iPhone 热点手机停在热点页面别锁屏，打开「最大兼容性」，Mac 的 Wi-Fi 关掉再打开；还不行就重启 Mac，或者用数据线连接。
安装命令一直没反应多半是网络问题：control+C 停止，确认已连热点再试。
Claude 说没有 Node装 Node.js（nodejs.org），然后告诉 Claude「装好 Node 了，帮我运行一下」。
系统弹出「安装软件，约 48 小时」点取消；如显示几分钟，就让它装完。
程序提示「已损坏」用 xattr -dr com.apple.quarantine，见第一部分。
不小心把命令粘贴进了 Claude Code按 esc 清掉；需要终端时按 command+N 开新窗口。
