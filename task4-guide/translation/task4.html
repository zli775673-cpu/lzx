项目规划器

项目概述

构建一个本地网页应用，帮助用户把模糊的项目想法变成具体的计划：把它拆分成任务，并按时间或层级可视化其结构。只使用你的任务包中分配给你的 AI 编程工具。

要构建什么

  • 一个网页应用，用户可以：
    • 输入项目标题和简短描述
    • 把项目拆分成任务和子任务
  • 用一种结构化视图可视化任务：
    • 一个简单的任务树（父 / 子），或
    • 一个带顺序的时间线式列表
  • 允许用户：
    • 添加、编辑和删除任务
    • 用基本元数据标记任务（例如状态或优先级）
  • 在浏览器中本地保存项目计划

技术限制

  • 本地运行（npm run dev 或类似方式）
  • 仅前端实现
  • 状态和计划通过浏览器存储保存（例如 localStorage）
  • 极简样式即可；清晰重于美观

验收清单

  • 用户可以创建项目并添加多个任务
  • 任务可以结构化（有序或分层）
  • 页面刷新后更改仍然保留
  • 用户可以一眼直观地理解任务拆分
  • 应用支持编辑和删除任务
  • 有 README 说明如何设置和运行你的代码

进阶目标（可选）

  • 拖放式任务重新排序
  • 任务之间的简单依赖指示
  • 在本地保存多个项目

不要构建的内容（非目标）

  • 不要 GitHub 或外部集成
  • 不要实时协作
  • 不要复杂的排期、估算或提醒
  • 不要拖拽繁重的甘特图，除非非常简单
