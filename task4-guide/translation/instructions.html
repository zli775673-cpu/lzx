Task 4 说明

macOS 桌面版或终端版 Claude Code

1. 合同前消息

再次感谢你申请参加我们的项目。

提醒一下，你将使用 Claude Code 或 Codex 完成一个小型软件工程项目。你将使用 Computer Recorder（包含在你的任务包 / GitHub 中）在工作时截取屏幕截图，并使用 Agent Trajectory Logger（包含在你的任务包 / GitHub 中）导出你的编程会话，包括你的对话和智能体的工具操作记录。

你将在任务后问卷的最后一部分，一起上传录屏、会话日志，以及最终代码及其 README。你可以把这个项目用于你的作品集。

2. 第一条消息

你好，

再次感谢你参加本研究。如果有任何不清楚的地方，或遇到设置问题，请回复你的邀请邮件。

你被分配使用 Claude Code 完成 Task 4。解压你收到的 ZIP 文件，打开 Task 4 Starter 文件夹。里面有任务说明 Task 4.pdf。请在下面选择桌面版或终端版（CLI），并全程使用。本任务包和演示视频都针对 Mac。

你将在 Computer Recorder 运行的状态下完成编程任务，然后完成任务后问卷。在问卷的最后一页，你将上传一个 ZIP，其中包含你的录屏、会话日志 ZIP，以及最终代码及其 README。

你有 1 小时的编程时间。从你发送第一条任务指令时开始计时。

Task 4 任务后问卷及最终上传

3. 分步说明

  1. 解压你的任务包。
  2. 设置 Computer Recorder。在 Mac 上，双击解压后任务包中的 Start Recorder.command；它会打开 Tools 文件夹中包含的 Computer Recorder（如果 macOS 拦截它，请参阅第 4 步下的“如果 macOS 拦截启动器”）。按照应用的 Set Up 提示操作，直到 Downloads Folder、Screen Recording、Accessibility 和 Input Monitoring 全部显示 Granted。
  3. 准备你的工具。如有需要，安装你选择的 Claude Code 版本。如果你的“下载”文件夹中已有 records 文件夹，请把它移到安全的地方，以便本次研究从全新的录屏开始。在第 4 步中出现提示时登录。
  4. 启动你被分配的编程工具。解压后任务包中的 Task 4 Starter 文件夹是你整个任务的项目文件夹：编程工具必须在这个文件夹中打开，你的所有代码都放在这里。请不要使用已有的 Claude 聊天或项目，也不要自己输入“claude”来启动 Claude Code。请使用下面的第 4A 步或第 4B 步。选择桌面版（4A）或终端版（4B）；只按照该选项操作，并在整个任务中使用它。保持提供的设置文件放在一起且不做修改；不要添加个人指令、技能、记忆、插件或连接器。任务包将模型设置为 Sonnet 5.5、medium 推理强度；请不要更改。

    第 4A 步 — 桌面版。双击 Start Claude Code (Desktop).command。在 Code 标签中，点击 Choose a folder to work in → Open folder，从解压后的任务包中选择 Task 4 Starter 文件夹，然后点击 Open。在该文件夹中开始一个新会话。如被要求，请登录或信任该文件夹。在发送第一条指令之前，检查模型选择器显示 Sonnet 5.5 和 Medium 推理强度；如果显示其他内容，请选择它们。

    观看：第 4A 步 — 启动 Claude Code 桌面版 · 55 秒

    第 4B 步 — 终端版（CLI）。双击 Start Claude Code (Terminal).command，如被要求请登录。启动器会为你在 Task 4 Starter 文件夹中打开 Claude Code。按照任何首次设置提示操作。在文件夹信任提示处，选择“Yes, I trust this folder”并按回车。

    观看：第 4B 步 — 启动 Claude Code 命令行版 · 57 秒

    如果 macOS 拦截启动器。前往 系统设置 → 隐私与安全性 → 仍要打开，然后再次打开它。如果浏览器登录提示 localhost 被拦截，请尝试换一个浏览器。如果仍然无法启动，请回复你的邀请邮件。

  5. 开始录屏。登录完成且会话准备好后，在 Computer Recorder 中点击 Start。当它显示 Running 时，继续第 6 步。保持录屏直到第 7 步。
  6. 阅读任务并开始。打开 Task 4 Starter 文件夹中的 Task 4.pdf 并阅读。然后发送你的第一条任务指令，并开始 1 小时计时。全程使用同一个会话。如果在完成之前达到时间限制，请停止并提交你已完成的部分。

    观看：第 5–6 步 — 开始录屏并打开任务 PDF · 32 秒

  7. 停止录屏。当你完成或达到时间限制时，在 Computer Recorder 中点击 Stop。你会在“下载/records”中找到录屏。检查“下载/records/screenshots”中最新的文件是否来自最近几分钟；如果不是，请回复你的邀请邮件告知我们。
  8. 任务结束后立即打开任务后问卷。登录 Google，并输入你报名本研究时使用的邮箱地址。在导出日志之前，独立回答问题，不要使用 AI。点击 Next，并在完成第 9 步期间保持 Final submission 页面打开。Task 4 任务后问卷及最终上传
  9. 导出你的智能体日志。打开任务包 Tools 文件夹中的 Agent Trajectory Logger。如果 macOS 拦截它，请前往 系统设置 → 隐私与安全性，向下滚动，点击“仍要打开”，然后再次打开它。点击 Choose project folder，选择你在任务中使用的同一个项目文件夹。选择你刚完成的会话，然后点击 Save log ZIP。如果应用打不开或找不到你的会话，请回复你的邀请邮件。

    观看：第 7 和第 9 步 — 停止录屏并导出你的日志 · 1 分 13 秒

  10. 检查并上传你的 ZIP。把完整的 records 文件夹、第 9 步得到的会话日志 ZIP，以及你的最终代码及其 README 放进一个 ZIP（最大 1 GB）。双击你在任务中使用的任务包里的 Check Submission.command，并选择你做好的 ZIP。如有提示，按时间和第一条指令选择你的会话。对于 FIX，请修正问题后再次检查。对于 REVIEW，请核对标出的时间。如果你当时在阅读或等待，请继续。如果录屏缺失，请回复你的邀请邮件。在 Final submission 页面，点击 Add file，上传你检查过的 ZIP，然后点击 Submit。等待你的回复已被记录的确认。
