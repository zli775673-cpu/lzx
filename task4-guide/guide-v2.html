3. 分步说明

第 1 步　解压任务包

解压后的文件夹包含：Check Submission.command、Start Claude Code (Desktop).command、Start Claude Code (Terminal).command、Start Recorder.command、Task 4 Instructions - Claude Code.docx、Task 4 Starter、Tools。

第 2 步　设置 Computer Recorder

在 Mac 上双击任务包里的 Start Recorder.command，它会打开 Tools 文件夹里的 Computer Recorder。如果 macOS 拦截，见第 4 步末尾的「如果 macOS 拦截启动文件」。按应用里的 Set Up 提示操作，直到以下 4 项都显示 Granted：

项目对应的 macOS 系统设置
Downloads Folder允许访问「下载」文件夹
Screen Recording隐私与安全性 → 屏幕与系统音频录制
Accessibility隐私与安全性 → 辅助功能
Input Monitoring隐私与安全性 → 输入监控

每项授权后，回到应用点 Check Again。

第 3 步　准备工具

  • 如有需要，安装你选择的 Claude Code 版本：
    • 安装说明：https://code.claude.com/docs/en/setup
    • 终端版 macOS 安装命令：curl -fsSL https://claude.ai/install.sh | bash
    • 桌面版需要 Claude 桌面应用，安装在「应用程序」文件夹中
  • 如果「下载」文件夹里已有 records 文件夹，先把它移到安全的地方，确保本次研究从全新的录屏开始。
  • 第 4 步中会提示你登录。

第 4 步　启动指定的编程工具

任务包里的 Task 4 Starter 是整个任务的项目文件夹：编程工具必须在这个文件夹中打开，所有代码也都放在这里。

请不要使用已有的 Claude 聊天或项目，也不要自己输入 claude 来启动 Claude Code。请使用下面的 4A 或 4B，二选一，全程只用这一种。

请保持提供的设置文件完整、不做修改；不要添加个人指令、技能、记忆、插件或连接器。任务包已把模型设为 Sonnet 5.5、medium 推理强度，请不要更改。

4A — 桌面版

  1. 双击 Start Claude Code (Desktop).command。
  2. 在 Code 标签中，点 Choose a folder to work in → Open folder，选中任务包里的 Task 4 Starter 文件夹，点 Open。
  3. 在该文件夹中开始一个新会话。如有提示，登录或信任该文件夹。
  4. 发送第一条指令前，检查模型选择器显示 Sonnet 5.5 和 Medium；如果显示的不是这两项，请手动选上。

项目概述

做一个本地运行的网页应用，帮助用户把模糊的项目想法变成具体计划：把项目拆分成任务，并按时间或层级展示结构。只能使用任务包中分配给你的 AI 编程工具。

要做什么

  • 一个网页应用，用户可以：
    • 输入项目标题和简短描述
    • 把项目拆分成任务和子任务
  • 用一种结构化视图展示任务：
    • 简单的任务树（父 / 子），或
    • 带顺序的时间线式列表
  • 允许用户：
    • 添加、编辑和删除任务
    • 给任务标记基本信息（例如状态或优先级）
  • 在浏览器本地保存项目计划

技术限制

  • 本地运行（npm run dev 或类似方式）
  • 只做前端
  • 状态和计划保存在浏览器存储中（例如 localStorage）
  • 样式简单即可，清晰比美观更重要

验收清单

  • ☐ 用户可以创建项目并添加多个任务
  • ☐ 任务可以结构化（有顺序或有层级）
  • ☐ 刷新页面后修改仍然保留
  • ☐ 用户能一眼看懂任务拆分情况
  • ☐ 支持编辑和删除任务
  • ☐ 有 README，说明如何安装和运行代码

加分项（可选）

  • 拖拽排序任务
  • 任务之间的简单依赖标记
  • 本地保存多个项目

不要做的（非目标）

  • 不要 GitHub 或其他外部集成
  • 不要实时协作
  • 不要复杂的排期、估时或提醒
  • 不要拖拽繁重的甘特图（除非非常简单）
